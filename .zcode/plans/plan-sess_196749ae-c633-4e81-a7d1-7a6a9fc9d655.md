# Velox Studio → Premium SaaS Trading Command Center

## Findings that shaped this plan
- Sidebar pages (finances, goals, tasks, routine, calculator) are **already deep** — the "feels generic" impression comes from **dead/stub code** (unrendered analytics tabs, fake notification bell, stubbed debt statuses, dead list view), **zero motion**, and **no mutation feedback**. The landing page **is** genuinely generic.
- UI primitives are hand-rolled native HTML + `cn()` + CSS-var tokens, no Radix. I will **match this convention** (forwardRef + cn + tokens) for all new primitives so everything stays cohesive.
- The design tokens (dark navy/charcoal + indigo + emerald/rose) are already strong — I'll **refine, not replace**.

## Decisions (confirmed with you)
- Order: **Foundation → Features → Landing**
- Direction: **Refine current dark theme** (better type scale, glass, shadows, motion)
- New deps: **framer-motion**, **cmdk**, **sonner**

## PHASE 2 — Trader Index (discipline score + alerts + revenge detection)
New: `src/lib/journal/trader-index.ts`, `src/components/dashboard/trader-index-gauge.tsx`, `src/components/dashboard/rule-alerts.tsx`, route `/dashboard/trader-index`.
- **Composite 0–100 Trader Index** = risk consistency + TOPG rule adherence + emotion-tag patterns + **revenge-trade detection** (position size ↑ within 60 min after a loss; 3+ trades in 30 min after a loss).
- Output: `overall` + 4 sub-scores + `RuleAlert[]` (severity, trade ref, message).
- **TraderIndexGauge** (animated radial) placed prominently on the main dashboard.
- **Rule-alert feed** surfaces in the topbar notification bell (wired in Phase 0.5) + a dedicated Trader Index page with per-rule breakdown and historical discipline trend.
- Animated counter + motion bar fills for sub-scores.

## PHASE 3 — Zenith AI Depth (extend Gemini integration)
New: `src/lib/zenith/patterns.ts`, `src/lib/zenith/weekly-review.ts`, `src/lib/zenith/query.ts`; extend `zenith-page.tsx`.
- **Cross-trade pattern detection** (computed locally, narrated by Gemini): "you lose X% of trades after 2 consecutive losses", worst hour, best session, Friday decay, etc.
- **Weekly AI review**: one-click → sends the week's metrics + patterns to Gemini → structured markdown review (strengths/leaks/next-week focus). Cached in localStorage.
- **NL query box**: user asks a question over their own trade history → serialize the relevant slice + metrics → Gemini answers from *their* data. Graceful local fallback when no API key.

## PHASE 4 — Backtesting Replay Engine
New: `src/lib/backtest/ohlc-generator.ts`, `src/lib/backtest/engine.ts`, `src/components/backtest/replay-page.tsx`, route `/dashboard/backtest`.
- Deterministic seeded synthetic OHLC generator (random-walk + volatility + trend regime) — reproducible, no external feed.
- Step/Play/speed controls; price chart with entry/exit markers + live unrealized P&L (motion-animated).
- Log simulated trades → P&L & R via existing `computeRMultiple` + same `Trade` shape → **localStorage** (kept separate from Supabase so the real journal is untouched).
- Replay results reuse `calculateMetrics` + `buildEquityCurve` → identical look to live analytics.
